Depósitos Premium

Gestioná el inventario de insumos separado por depósito o sucursal — por ejemplo, la cámara fría, el depósito seco y una segunda sucursal. Cada depósito tiene su propio stock y podés transferir mercadería entre ellos.

Plan requerido: el módulo de Depósitos está disponible en el plan Premium.

Para qué sirve

El módulo de Depósitos te permite separar el stock por ubicación física: cámaras, depósitos secos, sucursales. Cada depósito lleva su propio inventario y el sistema sabe exactamente cuántos insumos hay en cada uno. Podés:

  • Crear tantos depósitos como necesités (depósito seco, cámara fría, sucursal)
  • Ver el stock de cada producto o insumo por depósito
  • Transferir mercadería de un depósito a otro con trazabilidad completa
  • Configurar cuál es el depósito predeterminado para las ventas y el descuento de recetas

Crear un depósito

  1. Andá a Depósitos → Nuevo depósito.
  2. Ingresá un nombre descriptivo (por ejemplo: "Depósito seco", "Sucursal Norte").
  3. Agregá una descripción opcional.
  4. Guardá el depósito. Si querés que sea el predeterminado, marcalo con esa opción antes de guardar.

Depósito predeterminado

El depósito predeterminado es el que se descuenta automáticamente al cobrar un pedido o registrar una venta, sin necesidad de seleccionarlo cada vez. Siempre hay exactamente un depósito activo como predeterminado. Al marcar uno nuevo como predeterminado, el anterior pierde esa condición.

Ver stock por depósito

Desde la ficha de cada depósito podés ver el listado completo de productos e insumos con el stock actual en ese depósito. El stock de un mismo insumo puede diferir entre depósitos según las ventas, transferencias y ajustes realizados en cada uno.

Transferir stock entre depósitos

  1. Andá a Depósitos → Transferir stock.
  2. Seleccioná el depósito origen y el depósito destino.
  3. Buscá el producto o insumo que querés transferir.
  4. Ingresá la cantidad a transferir.
  5. Confirmá la transferencia. El sistema descuenta la cantidad del origen y la acredita en el destino de forma inmediata.

Atención: las transferencias son irreversibles desde la interfaz. Si necesitás corregir una transferencia, realizá una en sentido inverso con la misma cantidad.

Ajustes de stock

Los ajustes manuales de inventario (correcciones por diferencia de recuento, mermas, etc.) se realizan desde Productos → Stock. Al hacer un ajuste, el sistema te pide que seleccionés el depósito al que aplica el cambio.
