Listas de precio

Precios especiales por lista, para mayoristas, promociones o cualquier segmentación que necesites.

Crear una lista

Andá a Listas de precio → Nueva lista y ponele un nombre (por ejemplo, "Mayorista"). Después cargá un precio específico por producto dentro de esa lista.

Cómo se resuelve el precio de una venta

Al vender, el precio se resuelve en este orden:

  1. Precio explícito ingresado a mano en la venta (si corresponde).
  2. Precio de la lista configurada, si existe una para ese producto.
  3. Precio de venta por defecto del catálogo, como último respaldo.

Tip: si nunca configurás listas de precio, todo funciona igual que siempre — el sistema cae directo al precio de catálogo.
