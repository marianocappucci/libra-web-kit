Documentación de VentaLibra

Todo lo que necesitás para vender: catálogo, punto de venta, stock, compras y facturación.

Por dónde empezar

  1. Ingresá al sistema con el usuario y contraseña que te dio el administrador.
  2. Cargá tu catálogo: unidades, categorías y productos.
  3. Cargá el stock inicial de cada producto.
  4. Empezá a vender desde el punto de venta.
