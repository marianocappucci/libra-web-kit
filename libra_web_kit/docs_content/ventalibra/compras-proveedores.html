Compras a proveedores

Órdenes de compra y recepciones, con actualización automática de costo y stock.

Orden de compra (opcional)

Podés armar una orden de compra con líneas por producto y cantidad, para llevar seguimiento de lo pedido a un proveedor. Una orden queda marcada como parcial o recibida según lo que efectivamente se recepcione.

Recepción

Una recepción puede estar vinculada a una orden de compra, o cargarse directamente sin orden previa. Al confirmar una recepción:

  • Se suma el stock recibido de cada producto (o variante).
  • Se actualiza el costo del producto al último precio pagado.
  • Si está vinculada a una orden, se actualiza su estado según lo recibido.

Tip: no hace falta una orden de compra para recibir mercadería — podés cargar una recepción directa si el proveedor no requiere seguimiento formal.
