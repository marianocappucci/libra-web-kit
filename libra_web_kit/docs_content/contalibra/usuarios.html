Usuarios y permisos

Administrá quiénes pueden acceder al sistema y qué pueden hacer. Contalibra tiene dos roles: administrador y operador.

Roles del sistema

RolQué puede hacer
Administrador Acceso total: configuración, usuarios, módulos, reportes, backup y restore, logs del sistema.
Operador Acceso operativo: ventas, caja, productos, clientes. No puede modificar configuración ni ver logs.

Recomendación: Usá el rol Operador para el personal de caja o ventas. Reservá el rol Administrador para el dueño o encargado general.

Crear un usuario nuevo

  1. Andá a Administración → Usuarios en el menú lateral.
  2. Hacé clic en Nuevo usuario.
  3. Completá el nombre, nombre de usuario (login), contraseña y rol.
  4. Guardá. El usuario ya puede ingresar con esas credenciales.

Cambiar contraseña

Cualquier usuario puede cambiar su propia contraseña desde el ícono de usuario en la esquina superior derecha. Un administrador puede cambiar la contraseña de cualquier usuario desde Administración → Usuarios.

Desactivar un usuario

Para que un usuario ya no pueda ingresar, podés desactivarlo en lugar de eliminarlo. Así se conserva el historial de sus operaciones (ventas, cierres de caja, etc.).

  1. Andá a Administración → Usuarios.
  2. Buscá el usuario y hacé clic en Editar.
  3. Desmarcá Activo y guardá.

Atención: No elimines usuarios que tienen ventas o movimientos de caja registrados, ya que se perdería la trazabilidad de esas operaciones.

Auditoría y logs

El sistema registra las acciones importantes de cada usuario (login, ventas, cambios de configuración). Los administradores pueden revisar estos logs en Administración → Logs.
