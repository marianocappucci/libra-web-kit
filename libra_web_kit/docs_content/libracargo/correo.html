Correo saliente

El servidor de correo con el que LibraCargo manda los comprobantes y los enlaces para recuperar la contraseña.

Para qué hace falta

Sin correo configurado, dos cosas fallan:

  • Enviar por correo un comprobante, desde el detalle del comprobante.
  • ¿Olvidaste tu contraseña? en la pantalla de ingreso: el enlace para elegir una nueva se manda por correo.

Configurarlo

  1. Andá a Configuración → Integraciones → Email / SMTP (sólo administradores).
  2. Completá Servidor, Puerto, Usuario y Contraseña.
  3. Escribí el Remitente (si lo dejás vacío se usa el usuario; la mayoría de los proveedores exige que coincidan) y, si querés, el Nombre del remitente.
  4. Tocá Guardar.
  5. Tocá Probar conexión: dice a qué servidor se conectó y con qué usuario, o por qué no pudo.

El cuadro de arriba del formulario muestra el Estado: si está configurado, o si todavía se están usando las variables del servidor. La contraseña se guarda cifrada y no vuelve a mostrarse; para cambiarla, escribí una nueva. Borrar y usar la del servidor descarta lo guardado acá.

Con Gmail

Gmail no acepta tu contraseña normal para enviar desde una aplicación externa: necesitás una contraseña de aplicación.

  1. En tu cuenta de Google, andá a Seguridad y verificá que esté activada la Verificación en dos pasos.
  2. Entrá a las contraseñas de aplicación (myaccount.google.com/apppasswords).
  3. Escribí LibraCargo como nombre de la app y tocá Crear.
  4. Copiá la contraseña de 16 caracteres: no se vuelve a mostrar.
  5. Pegala en el campo Contraseña del formulario. Los valores para Gmail son servidor smtp.gmail.com, puerto 587 y como usuario tu dirección completa.

La pantalla incluye este mismo tutorial arriba del formulario.
