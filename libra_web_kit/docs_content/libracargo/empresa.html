El logo

Formatos aceptados: PNG, JPG y WebP, hasta 2 MB.

El SVG no se acepta, y es a propósito. Un SVG puede llevar scripts adentro, y el logo se sirve desde el mismo origen que el sistema — o sea, con tu sesión al alcance. La lista de formatos es blanca: lo que no está, no entra.

Quién puede cambiarlo

Los datos de la empresa los lee cualquier usuario —porque cualquiera imprime un papel con el membrete— pero sólo un administrador los edita: la identidad fiscal no es algo que se toque desde el mostrador.

Hay una sola configuración por instancia, y la base lo garantiza. Con dos configuraciones cargadas el sistema tendría que elegir una, y el papel podría salir con los datos de ayer sin que nadie se enterara.

Se guarda en tu base, no en el servidor

Tanto los datos como el logo viven en la base de datos de tu instancia. Dos consecuencias prácticas: cambiar el teléfono no requiere que nadie redespliegue nada, y todo esto viaja en el backup (ver Backup y restauración).
